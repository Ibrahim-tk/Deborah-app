# Your Oracle Clinician — prototype

Browser-based, frontend-only prototype of *Your Oracle Clinician* ("Deborah in Your Pocket").

```sh
npm i
npm run dev        # http://localhost:5173 → /mobile
npm run lint       # includes layer-boundary checks
npm run typecheck
```

Start with [CLAUDE.md](CLAUDE.md) and [docs/README.md](docs/README.md). Visual authority: [DESIGN.md](DESIGN.md) and [PRODUCT.md](PRODUCT.md).
